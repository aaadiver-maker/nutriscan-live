# NutriScan AI Food Scanner

Take or upload a photo of food and see it detected and classified in real
time, using the same pipeline built in Capstone Milestones 1 & 2:
YOLOv8n detection (crop with fallback) -> ResNet50 classifier (Variant 3),
17 food types.

Deployed on Streamlit Community Cloud, main file: `app.py`.
